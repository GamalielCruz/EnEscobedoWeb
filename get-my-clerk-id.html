🔑 Obtener Mi Clerk User ID

¿Para qué necesito esto?
Para que el dashboard muestre las órdenes de tu restaurante, necesitas asignar tu Clerk User ID como dueño de la tienda en Sanity Studio.

📝 Próximos pasos:

  1. Copia tu Clerk User ID usando el botón de arriba
  2. Ve a: http://localhost:3000/studio
  3. Busca "Tiendas Afiliadas" en el menú lateral
  4. Abre tu restaurante (ej: "Borona Pizza")
  5. Busca el campo "Usuario Dueño (ID de Clerk)"
  6. Pega tu Clerk User ID
  7. Haz clic en "Publish" o "Guardar"
  8. Recarga el dashboard: http://localhost:3000/dashboard
💡 Nota: Si no ves tu ID arriba, asegúrate de estar autenticado en la aplicación. Ve a http://localhost:3000 e inicia sesión primero.

📋 Instrucciones de Prueba

Objetivo: Verificar que el minimapa interactivo funciona correctamente en la página del carrito.

  1. Abre http://localhost:3000/basket en una nueva pestaña
  2. Agrega algunos productos al carrito si está vacío
  3. Selecciona el servicio "🏠 Entrega"
  4. Haz clic en "Usar mi ubicación"
  5. Permite permisos de ubicación cuando el navegador lo solicite
  6. Verifica que aparezca el minimapa con tu ubicación
  7. Prueba los controles del mapa (Ajustar, Confirmar, etc.)

🐛 Problemas Comunes y Soluciones

❌ El minimapa no aparece:

  • Verifica que hayas otorgado permisos de ubicación
  • Revisa la consola del navegador para errores de Google Maps
  • Asegúrate de que la API key de Google Maps esté configurada

⚠️ El marcador no se puede arrastrar:

  • Haz clic en "Ajustar" para activar el modo de edición
  • Verifica que el mapa esté completamente cargado

🔄 La dirección no se actualiza:

  • Verifica la conexión a internet
  • Revisa que la geocodificación inversa esté funcionando
